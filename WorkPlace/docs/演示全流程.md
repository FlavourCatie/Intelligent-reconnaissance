# 演示全流程（照这个顺序执行）

> 目标：一条命令跑完 **生成敌人 → 无人机覆盖扫描 → 发现目标 → 实物无人车出击**。
> 全程约 **4~6 分钟**。只有 **第 5 步（重启 subject4）必须手工**，其余都能复制粘贴。

---

## 总览

```
①清场 → ②启动三件套 → ③体检 → ④生成敌人 → ⑤手工重启 subject4 → ⑥跑演示 → ⑦收拾
                              ↑ 只在"换敌人布局"时需要
```

| 阶段 | 命令 | 耗时 |
|---|---|---|
| ① 清场 | `python WorkPlace\tools\kill_all.py` | 10 s |
| ② 启动 | CarlaUE4 → start.bat(选2) → subject4.exe | 1~2 min |
| ③ 体检 | `python WorkPlace\tools\kill_all.py --check` | 5 s |
| ④ 生成敌人 | `python WorkPlace\demo_midterm.py --spawn` | 5 s |
| ⑤ 重启场景 | 手动关/开 subject4.exe | 20 s |
| ⑥ 演示 | `python WorkPlace\demo_midterm.py` | 3~5 min |

## 第 4 步：生成敌人（只在"要换一批敌人"时做）

```powershell
python .\demo_midterm.py --spawn
```

默认会写入 **3 个敌人**：

```
第 1 步：生成敌人（3 个，环带 200~450 m，中心 -1875,-518）
[避让] 已载入 3 个禁飞区，撒点时会避开它们
[路侧] 敌人已从路中心横向挪开 14 m（留出车道）
```

* **环带 200~450 m**：离出生点足够近，几十秒就能发现
* **避开禁飞区**：否则无人机规划不出航线，会出现"有一架不出动"
* **离开路心 14 m**：否则无人车把"目标本身"当障碍，反复倒车卡死

> 只要敌人布局没变，**这一步可以跳过**，直接进第 6 步。

## 第 6 步：跑演示

```powershell
python .\demo_midterm.py
```

等价于下面这条（脚本会自动拼好，不用手敲）：

```
full_mission.py --uav-mode virtual --uav-route sweep
                --sweep-region auto --sweep-half 600 --sweep-partition rects
                --sweep-radius 300 --min-targets 3
                --duration 600 --recon-timeout 200 --ugv-deadline 360
                --view-roi auto --view-roi-max 500 --dispatch-gap 4
```

### 启动后应看到（关键几行）

```
[mission] 任务区域：中心 (-1674, -358)  ±420 m（840×840）
[mission] 扫描区域 = 局部地图任务区域（±420 m，840×840）
[mission]   子区域1/2/3: 三等分
[mission] 牛耕式覆盖扫描：R=300 m，条带间距 2R=600 m（实际 420 m）
[mission]   UAV1/UAV2/UAV3：航点与预计时间
[mission] 无人机航线已规划：{'UAV1': …, 'UAV2': …, 'UAV3': …}   ← 三架都要有
```

**要点**：`扫描区域` 必须等于 `任务区域`（就是小地图右图那个框），
即"扫的就是你看到的那一块"，不会多扫也不会漏扫。

## 第 7 步：演示中看什么、说什么

| 时间 | 画面 | 讲词 |
|---|---|---|
| 0~20 s | 三架三角形升到 250 m，阶段 `climb` → `crui` | "三架无人机按各自分配的子区域起飞" |
| 20~60 s | 三角形沿扫描线来回推进，拖出**彩色航迹** | "牛耕式覆盖扫描，条带间距 2R=600 m，保证不漏检" |
| 发现时 | 空心红圈 → 实心红点，HUD `已发现 N` | "进入 300 m 探测范围即判定发现" |
| 满 3 个 | 星标 + 虚线出现 | "按最小总距离把目标 1:1 分配给三台车" |
| 派车 | 三个方形**错峰**出发，各自转向目标 | "真实无人车 A\* 规划，错峰发车避免路口拥堵" |
| 飞完 | 该机图标与航迹**转灰** | "该机负责的子区域扫描完成" |
| 结束 | `结束原因：无人车全部结束 / 超时收尾` | "任务完成" |

**小地图**：灰色虚线 = 场景边界（地图范围）；**青绿实线 = 本轮搜索区域**（±420 m 左右，只比敌人分布大一点）；右图是同一区域的放大。
键盘：`1-6` 聚焦、`0` 总览、`+/-` 缩放、`s` 存图。

## 常见故障速查

| 现象 | 原因 | 处理 |
|---|---|---|
| subject4 没画面 / 立刻退出 | 开了两个 CarlaUE4，或飞控顺序错 | `kill_all.py` 后严格按第 2 步重来 |
| 无人机图标一直灰、不动 | 虚拟模式未生效 / 航线为空 | 看日志有没有 `牛耕式覆盖扫描` 与三条 `UAVx：…航点…` |
| 某架无人机没出动 | 目标全在禁飞区 | 重新 `--spawn`（会自动避让），或换 `--seed` |
| 一直不派车 | 发现数不足 `--min-targets` | 加 `--min-targets 2`；或等 `--recon-timeout` 结束 |
| 无人车卡住/反复倒车 | 目标占道、路口太窄 | `--spawn --off-road 22` + `--dispatch-gap 6` |
| 小地图卡顿 | 渲染太重 | `--extra "--view-interval 2.5"`（默认 1.5 s 刷一次）|

## 参数速查（需要微调时）

| 参数 | 默认 | 作用 |
|---|---|---|
| `--count` | 3 | 敌人数（= 车数，一车一敌） |
| `--radius` / `--radius-min` | 450 / 200 | 敌人撒点环带 |
| `--off-road` | 14 | 敌人离开路心多少米 |
| `--sweep-half` | **自动（= 局部地图任务区域）** | 想强制指定扫描范围时才用 |
| `--sweep-partition` | rects | 区域切 3 块 / 或全局条带 |
| `--sweep-radius` | 300 | 探测半径 R，条带间距 = 2R |
| `--dispatch-gap` | 4 | 三车错峰出发间隔 |
| `--duration` | 600 | 整轮时长上限 |
| `--view-interval` | 1.5 | 小地图刷新间隔（秒）|

**联动关系**：扫描区域 = 「无人机出生点 + 无人车出生点 + 近处敌人」的包围盒
（和小地图右图完全一致）。敌人撒到哪，包围盒就跟到哪，**都是自动的**，
不用再手算 `--sweep-half`。

**三架机都会出动**：默认把区域三等分成 3 块矩形，一机一块；
如果某一块整块落在禁飞区里（那一架会没航线），
会自动退回"全局条带按航程均衡"，保证三架都有任务 —— 日志会写：

```
[sweep] 分区扫描有 1 块被禁飞区覆盖（UAV1），改为全局条带均衡分配
```

## 附：被问到"为什么 3D 画面里看不到无人机飞"

**一句话回答**：这套课程包交付的 SDK 里，四旋翼的**飞行动力学通道不可用**，
所以无人机用运动学模型驱动（算法链路真实，视觉呈现为模拟），无人车完全驱动真实车辆。

**证据**（详见 `中期答辩_技术说明.md` 第 5 节）：

* control_kinetic_simply_global() 返回 200 但**位移 0.00 m**
* launch_kinetic() 用 18 组参数全部返回 None
* get_kinetic_data() **恒为 None**（驱动窗口只有心跳，从不提及任何飞机）
* M10 物理关不掉（会触发 UE4 断言崩溃），清速度/关重力调用无效，实测 9.8 m/s2 自由落体

**后续**：已与组员核对交付文件，新 SDK 正在对接；恢复后把 --uav-mode 从
virtual 改回 kinetic 即可切换真实飞行（UavRunner 那条路径一直保留）。
