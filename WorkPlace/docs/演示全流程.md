## 2. 无人机任务（kinetic 真实飞控）

### 2.1 覆盖巡查（敌人位置未知）

```powershell
cd IS\Intelligent-reconnaissance\WorkPlace
python missions\full_mission.py `
  --scene ..\Materials\practice\practice1_Scene `
  --uav-mode kinetic --uav-route sweep `
  --sweep-region "-1960,-720,-1660,-420" `
  --sweep-radius 100 --min-targets 1 `
  --duration 200 --no-ugv --no-view
```

要点：
* 三架机**各扫一块子区域**（`--sweep-partition rects`，默认），互不越界；
* 区域别开太大：巡航 4 m/s，300×300 m 一块约 75 s；
* 巡查途中发现目标后，**一机对一个目标**自动改航飞过去（`--uav-strike`，默认开）。

### 2.2 已知坐标直接飞过去

```powershell
python missions\full_mission.py `
  --scene ..\Materials\practice\practice1_Scene `
  --uav-mode kinetic --uav-route goto `
  --goto "-1600,-300;-1880,-180;-1600,-780" `
  --duration 190 --no-ugv --no-view
```

实测到点误差 **0.1 m**。

### 2.3 降落

默认 `--land`：收尾时把飞机降到 SITL 地板（= 出生高度）并稳住。
不要 `--no-land` 除非要保留空中画面。

## 4. 常见故障

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| 机高一直是 100.0 不动 | 启动顺序反了 / driver 没绑上 | 按 §1 重来 |
| 命令成功但飞机不动，且无 `Arming motors` | SITL 没起来 | 重启飞控；确认 `model.exe` 有 3 个 |
| 一进巡航速度飙到几十 m/s | 设定点太远（比例式接口） | 已用 `LOOKAHEAD` 修正；别把 `--uav-altitude` 调低 |
| 飞到一半 `health=0`、机高变 `?` | 撞了或互相撞 | 保证一机一个目标、区域不重叠 |
| 落过地后叫不起来 | SITL 已 disarm | 重启场景 |
| `unrecognized team id` | 少了 `-ConfigName=L1` | 加上 |

## 5. 无人机模式怎么选

| 模式 | 说明 | 用途 |
| --- | --- | --- |
| `kinetic`（推荐） | 真飞控：起飞/定高/巡航/改航/降落都实测通过 | 答辩演示 |
| `kinematic` | `set_transform` 沿航线搬，不依赖物理 | 飞控坏了时的备胎 |
| `virtual` | 纯数学，画面里飞机不动 | 只跑算法链路 |

## 6. 完整闭环演示（随机撒敌 → 侦查 → 派车 → 小地图）

```powershell

# ③ 跑完整任务（带小地图，第 130 秒自动存图）
python WorkPlace\missions\full_mission.py `
  --scene C:\Users\llq-5\Desktop\IS\material\practice\practice1_Scene `
  --uav-mode kinetic --uav-route sweep --area auto --sweep-radius 200 `
  --min-targets 3 --duration 330 --ugv-deadline 270 --dispatch-gap 6 `
  --shot-at 130
```

**判读标准**（2026-11-04 实测）：

```
发现目标 #0/#1/#2 士兵 (...)              <- 三机扫到三个敌人
已派车：{'UGV1': (...), 'UGV2': (...), 'UGV3': (...)}   <- 三个不同目标点
[UGV2] 到达目标附近, 停车。max_dev=4.7 m  <- 车到点
结束原因：无人车全部结束（到达或上报）
已保存小地图快照: WorkPlace/figs/live_snapshot_*.png
```

小地图上看：蓝色三角=无人机、橙/灰方块=无人车、**红实心=已发现敌人**、空心红圈=未发现、
青绿框=搜索区域、灰虚线=场景边界，另有禁飞区/雷区/电磁区图层。

**注意**：`--scene` 要指向 **subject4.exe 所在目录**（`material\practice\practice1_Scene`），
否则地图上的敌人和场景里的敌人会对不上。
