# 无人机-无人车协同侦查打击系统 · 能力总览

> 一句话：**三架无人机把任务区切成三块、各扫各的，边扫边报敌；三台无人车按“谁近谁去”接单，打到就转场，把整张图上的敌人清干净。**

本文只讲“做成了什么”和“为什么这么做”，不展开接口细节。

## 一、整体闭环

```
起飞 → 三分区牛耕侦查 → 发现敌人（上报，不追击）→ 按几何代价派车 → 到达开火 → 击杀后原地转场 → 下一个敌人 …… → 全部消灭 → 结束
```

全程在小地图上实时可见：无人机航迹、扫描覆盖、敌人三态、车辆位置与目标、禁飞区/雷区/电磁区。

## 二、做出来的效果特点

### 1. 对「随机敌人」的自适应

- 敌人每次随机撒在半图内（`--rect` 均匀撒点），位置、数量都不固定；程序**不依赖任何先验坐标**。
- 无人机发现一个就上报一个，指挥端**即时决定派几台车、派谁**；车打完后继续接新出现的敌人。
- 场景里放几个敌人就打到几个为止（启动时读 `targets.json` 得到总数，**打满才收工**，不会「打光已发现的就提前结束」）。

### 2. 无人机：真正的「无坐标」区域搜索

- 任务区沿长边切成 **3 块矩形**，一机一块，块内**牛耕式往返**扫描；
- 条带间距取 **1.4R**（R 为探测半径）：圆形探测足迹按 2R 排会留缝，1.4R≈√2·R 才能无缝拼满；
- 扫描线被禁飞区切断时，**按被切断的条带补扫**，避免「禁区边上漏一个」；
- 两段航线若横穿禁飞区，**自动插入绕行航点**（用规划器的可见图最短路），而不是硬闯；
- **发现敌人不改航**——只记录、上报，继续按自己的区域扫完再悬停；
- 单架越界/高度抖动只让**它自己**回撤修正，另外两架继续飞（早期版本会因为一架出事整组悬停，已修）。

### 3. 多车协同：会「让」也会「超」

- 三台车共享同一张路网与目标表，**目标不重复**（同一处只派一台，距离过近的点会去重）；
- 正前方有队友挡路：**先刹停等待**；队友连续停死超过 3 s → 判定为卡住，**自动 S 形侧偏超车**（最大横向偏移 5 m，越过后再保持 8 m 归位）；
- 前往同一方向的车辆按「先来后到」错峰发车（`--dispatch-gap`），避免在路口挤成一团；
- 卡住/无路可走的目标**不会被永久占用**：候选池只排除「已打死」和「正在打」的，失败的会自动被重新派车。

### 4. 打击闭环：打完就走，不等回程

- 车进入射程即开火（士兵用机枪、路障类用 40 mm）；
- **击杀瞬间就地转为空闲**，不必开到目标点报道，下一帧就能接新目标；
- 车辆转向代价、重复路径代价都算进「派给谁」的评价里，**少走回头路**；
- 新敌人若出现在某台「还在路上」的车附近（<150 m），会**优先留给那台车顺路解决**，而不是派远处的空车绕大圈。

### 5. 小地图：一屏看全

- **单张局部地图**居中，图例在左、六个体状态在右、总状态条在底部；
- 覆盖可视化用 **200 m 网格记账**，同一格只上一次色，飞几遍颜色都一样深，能看出哪块还没扫；
- 敌人三态一眼分清：**空心圈**未发现、**红色实心**已发现、**黄色 X** 已消灭；
- 道路、场景边界、禁飞区、雷区、电磁区、无人机航迹与目标点、车辆目标点全部同图叠加；
- 状态栏数字与运行态一致（已发现数直接取运行态，不从图元反推）。

### 6. 工程鲁棒性

- 起飞前等 SITL 解锁（20~60 s 属正常），超时才告警；
- 「无进展超时」而不是「固定超时」：只要飞机还在动就不判失败，避免长航时被误杀；
- 掉一架不影响全局：单架越界/航段不安全/高度偏差均降级处理；
- 场景路障可一键清除（`clear_obstacles.py`，带备份），避免车被沙袋堵死、倒车对撞。

## 三、算法特色（简）

| 模块 | 做法 | 为什么 |
| --- | --- | --- |
| 区域划分 | 沿长边等分矩形，一机一块 | 块内牛耕不交叉，天然不重复扫描 |
| 覆盖间距 | 条带 1.4R | 圆形足迹无缝拼接的最小浪费间距 |
| 禁区处理 | 扫描线切段 + 连接段绕行 + 断带补扫 | 先保证「线」安全，再补「缝」 |
| 派车 | 穷举 3×N 匹配，代价 = 距离 + 转向角×45 m + 重复路径×8 m | 规模小，穷举即最优；两项附加代价让车「顺路」 |
| 路径 | 路网骨架 A*，目标吸附到最近可通行点 | 车永远在路上走，不会穿楼 |
| 打击 | 距离判定 + 武器匹配 | 简单可靠，实测 5 发内击杀步兵 |
| 结束判据 | 打满场景总数 且 已发现全灭 | 避免「只打光看见的」提前收工 |
